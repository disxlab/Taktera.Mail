# Taktera.Mail — Roadmap

Полный поэтапный план развития приложения до версии 1.0.

Этапы:

- M00 — Engineering Baseline
- M01 — Domain & Application
- M02 — UI & Design System
- M03 — SQLite & Search
- M04 — MIME & Attachments
- M05 — IMAP Sync
- M06 — Accounts & OAuth
- M07 — Compose & SMTP
- M08 — Feature Complete
- M09 — Hardening
- M10 — Windows & macOS Platform Integration
- M11 — Alpha/Beta/RC
- M12 — Production Release

Подробные Issues с критериями приёмки находятся в GitHub и в `ISSUES_FULL.md`.

Основной принцип: каждый этап завершается проверяемым результатом, сборкой Release, тестами, обновлением документации и подтверждением отсутствия регрессий. Архитектурные изменения требуют утверждённого ADR.
